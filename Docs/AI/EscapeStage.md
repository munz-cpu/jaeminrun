# Battle 2: spaceship escape

Implemented 2026-09-13 in `Assets/Scenes/전투2.unity` using the existing live scene, terrain, player, house, ship and boss/arm sprites. The pre-change live scene (including unsaved user edits) is preserved at `Docs/AI/BeforeEscapeStage.unity`. No Git repository is present.

- Existing left/right movement and jumping remain available. The destination is the ship at x=237.49; entering its ground-level entrance boards automatically, animates takeoff, and opens the existing result scene.
- Eleven houses stand at x=15,35,...,215. Their concealment uses each house sprite's visible bounds, with a small edge margin, so the safe area matches the artwork. A player's full physical body inside the house is concealed automatically. Jumping above the roof exposes the player. Houses render in front of the player.
- The boss cycles while the player is between x=18 and x=220. After 4 seconds hidden, a 1-second camera rumble warns the player; the boss rises vertically over 0.5 seconds with a stronger rumble. During its 1.5-second exposed interval it scans ±1.4 world units, tilts and turns, then descends over 0.5 seconds. A player outside cover when it appears or while it watches dies instantly. The fast 0.1-second fist slam and impact rumble happen only for an exposed player; a concealed player is never targeted or shown the fist/target marker.
- `EscapeStageController` owns concealment display and boarding; `HutCover` defines coverage; `BossSlamHunter` owns targeting and procedural arm movement. All scene dependencies are serialized.
- `BattleEndController.objectiveVictoryOnly` reuses existing defeat/fade/score/retry behavior while allowing victory only through `CompleteObjective`. Defaults preserve battle 1. `BattleResult.ObjectiveVictory` selects the escape result title.
- The scene's old arena walls and unused boss/health HUD are disabled; a left boundary and escape HUD are added. The existing camera/confiner and static terrain are retained. Battle 2 is added to Build Settings for result-screen retry; startup scene order is unchanged.

Tuning: select Escape Stage for ship boarding bounds and references, boss for cycle timing, visible height, scan distance and tilt, or individual houses for cover configuration. `HutCover.useSpriteBounds` is enabled in the scene; disable it only when using a custom size/offset.
